# SolarUI - Animated Solar System Navigation Menu

قالب قائمة تفاعلية بتصميم نظام شمسي. متحركة بالكامل بـ HTML و CSS فقط بدون جافاسكربت.

![Preview](preview.jpg)

### ✨ المميزات

- **100% Responsive** - يعمل على الموبايل والتابلت والديسكتوب
- **Pure HTML & CSS** - لا يحتاج جافاسكربت او مكتبات خارجية
- **8 Planets** - كل كوكب بلون وتأثير Glow خاص بيه
- **Smooth Animations** - تأثيرات هوفر وانيميشن دخول احترافية
- **Easy to Customize** - غير الالوان والنصوص خلال دقايق
- **Glass Effect** - تصميم عصري مع Blur
- **Google Fonts** - خطوط Orbitron و Poppins
- **Well Commented Code** - كود نظيف ومنظم

### 🚀 طريقة الاستخدام

1.  حمل الملفات
2.  افتح `index.html` بالمتصفح
3.  لتغيير اسم الكوكب: عدل النص داخل `<a>` 
4.  لتغيير اللون: عدل `--color:#FFD700` داخل `<li>`
5.  لاستبدال الخلفية: استبدل ملف `stars.png`
